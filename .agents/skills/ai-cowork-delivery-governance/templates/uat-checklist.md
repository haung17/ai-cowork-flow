## QA Smoke Test 清單

在交給客戶 UAT 前，QA 必須確認以下項目：

- [ ] 登入 / 登出（各角色）
- [ ] 主要列表 / 查詢頁面載入正常
- [ ] 主流程新增 / 編輯 / 刪除操作正常
- [ ] 表單送出有正確回饋
- [ ] 匯出 / 下載功能正常（如適用）
- [ ] Email / 通知送出正常（如適用）
- [ ] 不同角色的權限控制正確
